# ADR-0015 — Bounded previews for tall high-resolution JPEGs

Date: 2026-10-29. Status: accepted for the owner's attached-JPEG failure report; native validation and remaining platform limits are recorded below and in the implementation log.

The authorized attachment is an 8192×12288 progressive JPEG (100,663,296 source pixels, 23,594,051 bytes). The existing isolated worker returns WorkerFailed because the Rust header decoder enforces a 12000-pixel side limit before ImageIO can downsample. A small generated JPEG with the same height reproduces “Image size exceeds limit”; the native C bridge independently has the same side guard. This is a budget rejection, not evidence of damage to the original.

For the read-only macOS file-backed JPEG adapter only, allow at most 16384 pixels per side and 144000000 total source pixels. The total pixel cap is the previous 12000×12000 maximum, now explicit. Other file formats and all byte/full-raster paths keep their existing 12000-pixel side and allocation limits. Apply matching geometry validation before native decoding and in the C bridge; the private rendition frame accepts the union of valid source dimensions under the same total cap. Keep 32–2048 output tiers, per-tier PNG caps, source revision/identity/read-only descriptors, ICC validation, orientation/SDR policy, 512MiB file/read budget, 12-second timeout, two shared media reservations and sampled 512MiB child RSS watchdog. No full-resolution pixel buffer is introduced in Rust, dependency/decoder upgrade, catalog migration or original write is authorized.

Use policy p2-v3-tall-jpeg-srgb8-preview so obsolete failure observations retry on the next visible request. Retain indexed positive p2-v2/p2-v1/M5/M1 renditions and historical job outcomes; do not purge caches or rescan originals as a repair. Map image-library limit errors to the explicit Unsupported preview-budget message, keeping malformed/decode failures distinct and backend causes private. The byte-path native color fallback requires the explicit internal ICC-policy condition; a generic Unsupported result cannot bypass a limit.

Regressions cover a generated tall JPEG, axis/pixel rejections before decode, unchanged PNG/byte-path limits, frame geometry and obsolete negative policies. The provided photo is kept outside Git and decoded only from a UUID-owned disposable copy, with independent SHA256/stat/identity manifests before/after. The current worker produces all five tiers; maximum observed direct-child sampled RSS is 119521280 bytes and the 2048px invocation takes 2.627s on this Mac. One invocation per tier, warm OS cache and sampled direct-child observations are not percentiles, cold-cache, full process-tree, native presentation or Windows evidence.
