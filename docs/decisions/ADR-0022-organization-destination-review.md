# ADR-0022 — read-only organization destination preflight

Date: 2026-10-31. Status: accepted for the owner's M2 planning continuation; persistence and execution remain gated.

Add destination identity and overlap review after the catalog-only organization preview. The renderer supplies selected asset UUIDs, typed template, exact preview fingerprint and a native picker session ID. Resolve the session only in Tauri; accept no renderer path, rows, approval or execution flag. A separate library adapter owns native reads and uses the existing catalog preview for snapshot validation. Admit one destination review at a time; bound inputs to 240 photos, 32 indexed roots and 96 directory components per chain.

Resolve native picker spelling (including Windows short-name/case aliases), then independently open every resolved directory component through held parent handles. Reject reparse/symlink components on that resolved chain and cloud placeholders. Bind final identity and volume to the picker observation. Retain all ancestor handles and compare native identities in both ancestor directions against every indexed root and app-data directory. An inaccessible or replaced root blocks the review. Reopen the selected location and rebuild the preview before returning; changed evidence fails instead of silently rebasing. Canonicalization is spelling resolution, never sufficient authorization. An ancestor alias to an indexed root must still fail identity overlap; this review does not reserve a path or claim race-proof future write authorization.

Apply the existing native no-recall/reparse/placeholder root guard before OS spelling resolution and again during final revalidation; retain the selected object handle throughout. This is not a claim that simulated fixtures validate every cloud provider's hydration behavior.

Return only display text and a versioned fingerprint bound to the preview, native destination path/identity/volume and root observations. Native paths stay in Rust. Target existence, native case/Unicode collision rules, complete companions, capacity/fidelity, write capability, immutable persisted plans, approvals and executor/recovery remain unchecked. The response explicitly has persisted=false and executionAvailable=false. The UI distinguishes checked identity/overlap from these unresolved requirements, retains an observation on picker cancellation, exposes failed checks/retry, marks catalog changes stale and disposes late requests after close or preview replacement.

Within the active catalog, compare decimal revisions monotonically with BigInt: an older polled status cannot invalidate a newer preview/response. An observed revision newer than the preview does invalidate it. Backend fingerprint revalidation remains mandatory regardless of frontend polling order.

At this slice's initial acceptance, keep catalog schema 2 until retained migration snapshots are verified on Windows. [ADR-0023](ADR-0023-retained-organization-drafts.md) subsequently supplies the scoped application-snapshot publication adapter, migration interruption fixtures and schema-3 retained drafts. It supersedes this persistence prerequisite without enabling original-file publication or relaxing M2/P4/preservation gates. The destination preflight itself remains a temporary read-only observation.

Validate with generated directories/media and native picker-session fixtures only. No destination probe file, directory creation, file reservation, source rewrite or catalog write occurs in production preflight. Test IPC authority, sibling/equal/ancestor/descendant/app-data overlap, stale previews, wrong volume, missing paths, resolved-chain junction rejection, UI cancellation/errors/staleness and source/destination preservation. Desktop fixtures create their own destination and retain a destination-only file; fixture commands remain production-excluded. See [M2 contract](../M2_ORGANIZATION_PREVIEWS.md) and [implementation log](../IMPLEMENTATION_LOG.md) for actual evidence and limits.
