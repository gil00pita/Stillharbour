# Stillharbour - Library features: acceptance and failure scenarios

v1.2 | 2026-10-26

**These are 62 required scenario specifications, not executed tests.** They add to 85 AC and 40 PS scenarios: 187 specified scenarios in the complete package. Use disposable generated fixtures; live/native/provider tests require appropriate authorization and an actual supported environment. Record real results in IMPLEMENTATION_LOG.md.

## Evidence standard

For every claimed pass, record platform, app/runtime versions, fixture manifests, command/result and checked source/destination/catalog state. Test interruption at each relevant journal transition. A mocked provider or successful document check is not a native API test, original-fidelity proof or demonstrated zero-loss application. Preserve prior AC/PS regression coverage.
