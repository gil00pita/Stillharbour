# Performance acceptance scenarios — P0 evidence checklist

The named addendum checklist was absent when P0 began on 2026-10-28. This file reconstructs its P0 checks from the owner's authorised prompt, [PERFORMANCE_PLAN.md](PERFORMANCE_PLAN.md) and existing preservation rules; it does not claim to reproduce a missing external document. Proposed targets remain proposals. See [PERFORMANCE_BASELINE.md](PERFORMANCE_BASELINE.md) for actual results and evidence.

A status applies only to the stated platform/build/workload. **Passed** requires completed supporting evidence; **failed** means the stated check/target was exercised and unmet; **blocked** identifies a missing prerequisite; **not run** means no result was collected. A debug native functional pass is not a release performance pass. Do not combine those scopes into a single product claim.
