## Concrete recovery regression anchors

These identify executable cases for gate review, rather than replacing the acceptance scenarios with ADR summaries.

Planning anchors are in [organization/tests.rs](../crates/core/src/organization/tests.rs): `presets_resolve_capture_local_time_and_keep_extension_case`, `no_silent_filesystem_date_fallback_and_explicit_missing_value_policy`, `rejects_injected_values_reserved_devices_and_unsafe_components`, `stable_sequence_and_fingerprint_bind_policy_revision_and_native_identity` and `every_collision_participant_is_blocked_and_targets_stay_visible`. Immutable catalog/template guards are `plan_content_is_retained_and_digest_and_catalog_binding_are_verified` and `template_versions_compare_and_swap_and_cannot_be_rewritten` in [operation_store.rs](../crates/core/src/library/operation_store.rs).

Export anchors are `spreadsheet_cells_are_quoted_and_formula_safe_without_losing_json_text` in [operations.rs](../crates/core/src/operations.rs), and `review_export_ipc_never_accepts_renderer_paths_names_bytes_or_overwrite_flags` / `review_export_publishes_exact_bytes_and_never_replaces_existing_files` in [review_export.rs](../crates/core/src/library/review_export.rs). Equivalent-input copy effect cases in `catalog_journal.rs` prove that a new draft does not silently allocate a second namespace for an already verified unchanged effect.

AC-081 anchors are `shared_scope_locks_block_copy_and_recovery_without_a_journal_change_then_release` in `executor.rs`, `generated_original_coordination_retains_lease_through_commit_and_defers_stopped_scans` in [coordination_tests.rs](../crates/core/src/executor/rename_fixture/coordination_tests.rs), and the actual monitor cases in [monitor.rs](../crates/core/src/library/monitor.rs). Backup-style readers use the same shared lease interface; an actual M4 backup adapter is not claimed.

AC-084 anchors in [catalog.rs](../crates/core/src/catalog.rs) are `wal_snapshot_is_independently_openable_and_never_replaces`, `process_exit_during_migration_retains_a_consistent_catalog_and_backup` and the schema-8 `import_destination_migration_retains_v7_identity_and_snapshot_and_rolls_back_collision`. [catalog_snapshot.rs](../crates/core/src/filesystem/catalog_snapshot.rs) also tests native relative, flushed, no-replace snapshot publication. These establish the recorded SQLite snapshot/migration behavior, not physical power-loss durability or general imported-catalog mutation authority.
