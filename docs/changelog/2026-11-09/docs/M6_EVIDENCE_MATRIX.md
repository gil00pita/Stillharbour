2026-11-03. This is a release-gap index, not a certification or a new execution receipt. All 85 original AC and all 40 PS scenarios are retained. Read the complete normative scenarios in [acceptance tests](ACCEPTANCE_TESTS.md) and [preservation tests](PRESERVATION_TESTS.md); the short labels below do not replace them. Linked milestone documents own exact tests, commands, fixtures, stages, CI identities and historical failures. Their evidence applies only to those recorded builds and scopes, not automatically to the current or eventual signed package.

**Partial** means implementation/fixture evidence exists but full release qualification remains open. **Development accepted** identifies the bounded M5 gate only. **Blocked** requires missing external/package evidence. **Deferred** is an already specified disabled follow-on, not removal of an applicable v1 requirement. No row currently certifies release. The [readiness record](M6_RELEASE_READINESS.md) gives the next executable gates and actual current checks. Approved N extensions require additional LF scenarios; this M6 start authorizes no new N slice.
